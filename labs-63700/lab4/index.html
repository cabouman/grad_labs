Module 1: Power Spectral Density of an Image Steps 1 to 4. Set up the code, compute one-block estimates, build an averaged estimate, and check it with Parseval's relation.

Step 1: Set Up lab4.py

Copy these helpers into lab4.py. For the grayscale image, load_image returns shape \((1, H, W)\). The PSD functions take shape \((H, W)\), so pass them x[0]. 

import numpy as np
import torch
from PIL import Image
import matplotlib.pyplot as plt


def load_image(path):
    """Read an 8-bit image file as a (C, H, W) float64 tensor in [0, 1]."""
    a = np.asarray(Image.open(path), dtype=np.float64) / 255.0
    if a.ndim == 2:
        a = a[:, :, None]
    return torch.from_numpy(a).permute(2, 0, 1).contiguous()


def save_image(x, path):
    """Clip a (C, H, W) tensor, C = 1 or 3, to [0, 1] and save it as an 8-bit PNG."""
    a = (x.clamp(0.0, 1.0) * 255.0).round().to(torch.uint8)
    a = a.permute(1, 2, 0).numpy()
    if a.shape[2] == 1:
        a = a[:, :, 0]
    Image.fromarray(a).save(path)


def freq_grid(n):
    """Return n by n grids mu (down rows) and nu (across columns) in [-pi, pi)."""
    w = 2 * torch.pi * (torch.arange(n, dtype=torch.float64) - n // 2) / n
    return torch.meshgrid(w, w, indexing="ij")


def spec_anal(x, n):
    """Return the log of |DFT|^2 / n^2 of the centered n by n block of x (H, W), centered."""
    H, W = x.shape
    i, j = (H - n) // 2, (W - n) // 2
    z = x[i:i + n, j:j + n]
    s = torch.fft.fft2(z).abs() ** 2 / n**2
    return torch.log(torch.fft.fftshift(s))


def plot_log_psd(log_s, title, path):
    """Save a surface plot of an (n, n) log PSD, centered to match freq_grid(n)."""
    mu, nu = freq_grid(log_s.shape[0])
    fig = plt.figure(figsize=(6, 4.8))
    ax = fig.add_subplot(projection="3d")
    surf = ax.plot_surface(nu.numpy(), mu.numpy(), log_s.numpy(),
                           cmap="viridis", linewidth=0, antialiased=True)
    ax.set_xlabel(r"$\nu$ (radians/sample)")
    ax.set_ylabel(r"$\mu$ (radians/sample)")
    ax.set_zlabel("natural log of PSD")
    ax.set_title(title)
    fig.colorbar(surf, ax=ax, shrink=0.6, pad=0.12)
    fig.tight_layout()
    fig.savefig(path, dpi=130)
    plt.close(fig)

Step 2: The One-Block Estimate

Model the image, after its mean is removed, as a zero-mean wide-sense stationary random process \(X(m,n)\) with autocorrelation \(R(k,l) = E\big[X(m,n) X(m+k, n+l)\big]\). Its power spectral density is

$$ S(e^{j\mu}, e^{j\nu}) = \sum_{k=-\infty}^{\infty} \sum_{l=-\infty}^{\infty} R(k,l) \, e^{-j(\mu k + \nu l)} \ . \tag{1} $$

For an \(N \times N\) block \(z(m,n)\) with DFT \(Z(k,l)\), the simplest estimate at \(\mu = 2\pi k/N\), \(\nu = 2\pi l/N\) is

$$ \hat S(k,l) = \frac{1}{N^2} \, |Z(k,l)|^2 \ . \tag{2} $$

spec_anal estimates the power spectral density by computing the logarithm of (2) over the block at the center of the image. It does not subtract the block mean, so its value at zero frequency, \(N^2\) times the squared mean, stands far above the rest.

Step 3: The Averaged Estimate

Write better_spec_anal(x), which computes a better estimate of the power spectral density of x. It should:

  • Subtract the mean of the \(320 \times 320\) region at the center of x, and cut that region into 25 non-overlapping \(64 \times 64\) blocks \(z_b(m,n)\), \(b = 1, \dots, 25\).
  • Multiply each block by the 2-D separable Hamming window \(w(m,n) = h(m)\, h(n)\), the outer product of torch.hamming_window(64, periodic=False, dtype=torch.float64) with itself.
  • Compute the squared DFT magnitude \(|Z_b(k,l)|^2\) of each windowed block, and average across the 25 blocks:
$$ \hat S(k,l) = \frac{1}{25} \sum_{b=1}^{25} \frac{|Z_b(k,l)|^2}{\sum_{m,n} w(m,n)^2} \ . \tag{3} $$

The denominator makes the expected value of \(\hat S\) equal to \(\sigma^2\) at every frequency for white noise of variance \(\sigma^2\). Cut the blocks with reshape and permute, and transform all of them with one call to torch.fft.fft2. Return the estimate itself, not its log.

Step 4: The Parseval Check

By Parseval's relation, \(\sum_{k,l} |Z_b(k,l)|^2 = N^2 \sum_{m,n} |w(m,n) z_b(m,n)|^2\), so the mean of (3) over all \(64^2\) frequencies is a weighted sample variance of the region:

$$ \frac{1}{64^2} \sum_{k,l} \hat S(k,l) = \frac{1}{25} \sum_{b=1}^{25} \frac{\sum_{m,n} w(m,n)^2 \, z_b(m,n)^2}{\sum_{m,n} w(m,n)^2} \ . \tag{4} $$

Task 4a. Compute the right side of (4) from the blocks, without an FFT. Report both sides, the relative error (absolute difference divided by the right side), and the ordinary sample variance of the region.

Pass criterion. The relative error is at round-off. An error by a factor of \(64^2\) means the DFT normalization is wrong. Another constant factor means the estimate and the check use different window sums. The two variances differ, because the window weights the center of each block most.
