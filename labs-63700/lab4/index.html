Module 1: Power Spectral Density of an Image Steps 1 to 4. Set up the code, compute one-block estimates, build an averaged estimate, and check it with Parseval's relation.

Step 1: Set Up lab4.py

Copy these helpers into lab4.py. The first three are the same as in Lab 3. spec_anal computes the simplest PSD estimate, which Step 2 explains, and plot_log_psd makes the surface plots, so that everyone's plots can be compared. 

import numpy as np
import torch
from PIL import Image
import matplotlib.pyplot as plt


def load_image(path):
    """This function reads an 8-bit image file and returns it as a tensor.

    path     path to a PNG or TIFF file
    returns  (C, H, W) float64 tensor with values in [0, 1]
    """
    a = np.asarray(Image.open(path), dtype=np.float64) / 255.0
    if a.ndim == 2:
        a = a[:, :, None]
    return torch.from_numpy(a).permute(2, 0, 1).contiguous()


def save_image(x, path):
    """This function clips an image to [0, 1] and writes it as an 8-bit PNG.

    x        (C, H, W) tensor with C = 1 or C = 3
    path     output file name, ending in .png
    """
    a = (x.clamp(0.0, 1.0) * 255.0).round().to(torch.uint8)
    a = a.permute(1, 2, 0).numpy()
    if a.shape[2] == 1:
        a = a[:, :, 0]
    Image.fromarray(a).save(path)


def freq_grid(n):
    """This function returns an n by n grid of frequencies in [-pi, pi).

    mu varies down the rows and nu varies across the columns.  The grid
    matches the order of an FFT after torch.fft.fftshift.
    """
    w = 2 * torch.pi * (torch.arange(n, dtype=torch.float64) - n // 2) / n
    return torch.meshgrid(w, w, indexing="ij")


def spec_anal(x, n):
    """This function estimates the power spectral density from one block.

    The block is the n by n square at the center of x.  The function
    computes |DFT|^2 / n^2 of the block and centers it so that it matches
    freq_grid(n).  The mean of the block is not subtracted.

    x        (H, W) float64 tensor
    n        int, the block size
    returns  (n, n) float64 tensor, the natural log of the estimate
    """
    H, W = x.shape
    i, j = (H - n) // 2, (W - n) // 2
    z = x[i:i + n, j:j + n]
    s = torch.fft.fft2(z).abs() ** 2 / n**2
    return torch.log(torch.fft.fftshift(s))


def plot_log_psd(log_s, title, path):
    """This function saves a surface plot of a log power spectral density.

    log_s    (n, n) float64 tensor, centered to match freq_grid(n)
    title    string, the title of the plot
    path     output file name, ending in .png
    """
    mu, nu = freq_grid(log_s.shape[0])
    fig = plt.figure(figsize=(6, 4.8))
    ax = fig.add_subplot(projection="3d")
    surf = ax.plot_surface(nu.numpy(), mu.numpy(), log_s.numpy(),
                           cmap="viridis", linewidth=0, antialiased=True)
    ax.set_xlabel(r"$\nu$ (radians/sample)")
    ax.set_ylabel(r"$\mu$ (radians/sample)")
    ax.set_zlabel("natural log of PSD")
    ax.set_title(title)
    fig.colorbar(surf, ax=ax, shrink=0.6, pad=0.12)
    fig.tight_layout()
    fig.savefig(path, dpi=130)
    plt.close(fig)

load_image returns a tensor of shape \((1, H, W)\) for a grayscale image. The PSD functions in this lab take a 2-D tensor of shape \((H, W)\), so pass them x[0].

Step 2: The One-Block Estimate

Model the image, after its mean is removed, as a sample of a 2-D random process \(X(m,n)\) that has zero mean and is wide-sense stationary. Its autocorrelation is \(R(k,l) = E\big[X(m,n) X(m+k, n+l)\big]\), and its power spectral density is the DSFT of the autocorrelation:

$$ S(e^{j\mu}, e^{j\nu}) = \sum_{k=-\infty}^{\infty} \sum_{l=-\infty}^{\infty} R(k,l) \, e^{-j(\mu k + \nu l)} \ . \tag{1} $$

The simplest estimate uses one \(N \times N\) block \(z(m,n)\) of the image. Let \(Z(k,l)\) be its \(N \times N\) DFT. The estimate at the frequency \(\mu = 2\pi k/N\), \(\nu = 2\pi l/N\) is

$$ \hat S(k,l) = \frac{1}{N^2} \, |Z(k,l)|^2 \ . \tag{2} $$

This is what spec_anal computes for the block at the center of the image. It returns the natural log of the estimate, because the PSD of an image spans many orders of magnitude. spec_anal does not subtract the mean of the block, so its value at zero frequency is \(N^2\) times the squared mean of the block. That value stands far above the rest of the surface.

Step 3: The Averaged Estimate

A better estimate averages the one-block estimate over many blocks, and it multiplies each block by a window before the DFT. Use 25 non-overlapping \(64 \times 64\) blocks, arranged as a \(5 \times 5\) grid that covers the \(320 \times 320\) region at the center of the image. Subtract the mean of that region from it first. Call the blocks \(z_b(m,n)\) for \(b = 1, \dots, 25\).

The window is the separable 2-D Hamming window \(w(m,n) = h(m)\, h(n)\), where \(h\) is the 1-D Hamming window of length 64. Let \(Z_b(k,l)\) be the \(64 \times 64\) DFT of \(w(m,n)\, z_b(m,n)\). The averaged estimate is

$$ \hat S(k,l) = \frac{1}{25} \sum_{b=1}^{25} \frac{|Z_b(k,l)|^2}{\sum_{m,n} w(m,n)^2} \ . \tag{3} $$

The denominator makes the estimate correct for white noise. If the blocks are white noise with variance \(\sigma^2\), then the expected value of \(\hat S(k,l)\) is \(\sigma^2\) at every frequency. With \(w = 1\) and one block, equation (3) is equation (2), except that (3) subtracts the mean.

    """This function estimates the power spectral density by averaging 25 blocks.

    x        (H, W) float64 tensor with H, W >= 320
    returns  (64, 64) float64 tensor, the estimate of equation (3),
             centered to match freq_grid(64)
    """

Three requirements.

  • The 1-D window is torch.hamming_window(64, periodic=False, dtype=torch.float64), and the 2-D window is its outer product with itself.
  • The function returns the estimate itself, not its log, so that Step 4 can check it.
  • The 25 blocks are cut out with reshape and permute, and one call to torch.fft.fft2 transforms all of them. There is no loop over blocks.

Step 4: The Parseval Check

Parseval's relation for the DFT of an \(N \times N\) array says \(\sum_{k,l} |Z_b(k,l)|^2 = N^2 \sum_{m,n} |w(m,n) z_b(m,n)|^2\). Apply it to equation (3). The mean of the estimate over all \(64^2\) frequencies must then equal a weighted sample variance of the region:

$$ \frac{1}{64^2} \sum_{k,l} \hat S(k,l) = \frac{1}{25} \sum_{b=1}^{25} \frac{\sum_{m,n} w(m,n)^2 \, z_b(m,n)^2}{\sum_{m,n} w(m,n)^2} \ . \tag{4} $$

Task 4a. Compute the right side of (4) directly from the image blocks, without any FFT. Report both sides of (4) and the relative error, which is the absolute difference divided by the right side. Also report the ordinary sample variance of the \(320 \times 320\) region.

Reading the check. The relative error should be at the level of round-off. If it is off by a factor of \(64^2\), the DFT normalization is wrong. If it is off by another constant factor, the estimate and the check divide by different window sums. The two variances differ, because the window gives the most weight to the center of each block.

Step 6: The AR Process

Filter \(x\) with the 2-D IIR filter whose transfer function is

$$ H(z_1, z_2) = \frac{3}{1 - 0.99 z_1^{-1} - 0.99 z_2^{-1} + 0.9801 z_1^{-1} z_2^{-1}} \ , \tag{5} $$

where \(z_1\) goes with \(m\) and \(z_2\) goes with \(n\). Call the output \(y\). The output is a 2-D autoregressive process, because each output pixel is a weighted sum of earlier outputs plus new noise.
