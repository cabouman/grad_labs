Ground Rules

  • All filtering code is in PyTorch, in a single file named lab3.py. Use the labs conda environment you built in Lab 2. You may use NumPy and matplotlib for plotting.
  • lab3.py holds functions and nothing else. Run your experiments from a separate script that imports it.
  • Every function has the exact signature given on this page, and a docstring that says what it does, what its inputs are, and what it returns. Keep the docstrings short.
  • Read each image and scale it to the range \([0,1]\) by dividing by 255. Do all arithmetic in float64.
  • A color image is a tensor of shape \((3, H, W)\): the red, green, and blue channels, each \(H\) rows by \(W\) columns. Every filter is applied to each channel separately.
  • The index \(m\) counts rows, from top to bottom, and the index \(n\) counts columns, from left to right.
  • Pixels outside the image are zero. This is called a free boundary condition.
  • A filter output can fall outside \([0,1]\). Keep the values as they are for computation, and clip them to \([0,1]\) only when you display or save an image.
  • No Python for loop over pixels, except in the one function in Module 3 that asks for one.

Step 1: Set Up lab3.py

Copy these helpers into lab3.py. Reading and writing files is not the point of this lab, and the two frequency helpers fix the frequency grid so that everyone's numbers can be compared. 

import numpy as np
import torch
import torch.nn.functional as F
from PIL import Image


def load_image(path):
    """This function reads an 8-bit image file and returns it as a tensor.

    path     path to a PNG or TIFF file
    returns  (C, H, W) float64 tensor with values in [0, 1]
    """
    a = np.asarray(Image.open(path), dtype=np.float64) / 255.0
    if a.ndim == 2:
        a = a[:, :, None]
    return torch.from_numpy(a).permute(2, 0, 1).contiguous()


def save_image(x, path):
    """This function clips an image to [0, 1] and writes it as an 8-bit PNG.

    x        (C, H, W) tensor with C = 1 or C = 3
    path     output file name, ending in .png
    """
    a = (x.clamp(0.0, 1.0) * 255.0).round().to(torch.uint8)
    a = a.permute(1, 2, 0).numpy()
    if a.shape[2] == 1:
        a = a[:, :, 0]
    Image.fromarray(a).save(path)


def box_kernel(p):
    """This function returns the (2p+1) by (2p+1) averaging kernel.

    Every entry equals 1 / (2p+1)^2, so the entries sum to 1.
    """
    k = 2 * p + 1
    return torch.full((k, k), 1.0 / k**2, dtype=torch.float64)


def freq_grid(n):
    """This function returns an n by n grid of frequencies in [-pi, pi).

    mu varies down the rows and nu varies across the columns.  The grid
    matches the order of the output of fft_magnitude.
    """
    w = 2 * torch.pi * (torch.arange(n, dtype=torch.float64) - n // 2) / n
    return torch.meshgrid(w, w, indexing="ij")


def fft_magnitude(h, n):
    """This function returns |FFT| of a kernel zero padded to n by n.

    h        (K, L) tensor with K, L <= n
    returns  (n, n) float64 tensor, centered so that frequency zero is at
             row n // 2 and column n // 2, matching freq_grid(n)
    """
    return torch.fft.fftshift(torch.fft.fft2(h, s=(n, n))).abs()

Step 2: The Frequency Response

The low-pass filter in this module is the \(9 \times 9\) average, with point spread function

$$ h(m,n) = \left\{ \begin{array}{ll} 1/81 & \mbox{for } |m| \le 4 \mbox{ and } |n| \le 4 \\ 0 & \mbox{otherwise} \ . \end{array} \right. \tag{1} $$

The frequency response of a filter is the discrete space Fourier transform (DSFT) of its point spread function,

$$ H(e^{j\mu}, e^{j\nu}) = \sum_{m=-\infty}^{\infty} \sum_{n=-\infty}^{\infty} h(m,n) \, e^{-j(\mu m + \nu n)} \ , \tag{2} $$

where \(\mu\) is the frequency along \(m\) (down the rows) and \(\nu\) is the frequency along \(n\) (across the columns). Both are in radians per sample.

The sum in (2) separates into a sum over \(m\) times a sum over \(n\), and each of those is a finite geometric series. Your answer should be a real function of \(\mu\) and \(\nu\). State its value at \(\mu = \nu = 0\).

Step 3: The FIR Filter and Its Checks

An FIR filter with point spread function \(h\) computes the 2-D convolution

$$ y(m,n) = \sum_{k} \sum_{l} h(k,l) \, x(m-k, n-l) \ , \tag{3} $$

with \(x(m,n) = 0\) outside the image. Store the kernel as an array of odd size \(K \times L\) whose center entry, h[K//2, L//2], holds \(h(0,0)\). 

def fir_filter(x, h):
    """This function filters each channel of an image with an FIR kernel.

    x        (C, H, W) float64 tensor
    h        (K, L) float64 tensor, K and L odd, h[K//2, L//2] = h(0, 0)
    returns  (C, H, W) float64 tensor, the convolution of equation (3)
    """

Three requirements.

  • Zero padding, so that the boundary is free as stated in the ground rules.
  • The output has the same shape as the input.
  • Built from torch.nn.functional.conv2d, with no loop over pixels. Treat the channels as a batch, so that one call filters all three.
conv2d does not compute convolution. It computes correlation, which is equation (3) with \(h(k,l)\) replaced by \(h(-k,-l)\). To get (3) you must flip the kernel in both axes before you pass it to conv2d. Every kernel in this lab is symmetric, so this mistake would not change any result here. It would change the result for the next kernel you use, so get it right now.

Then repeat the test with the nonsymmetric kernel below, which is the test that catches a missing flip.

Task 3b. The FFT check. The DFT of \(h\) zero padded to \(N \times N\) equals the DSFT (2) sampled at the frequencies \(\mu = 2\pi k/N\) and \(\nu = 2\pi l/N\). The zero padding puts \(h(0,0)\) at a corner of the array rather than at its center. That shift changes only the phase of the DFT, so the magnitudes still agree. Compute

           - box_response(mu, nu, 4).abs()).abs().max()

and report it. This number tests your hand derivation, not just your code.

Reading the checks. The three numbers should all be at the level of round-off. If the impulse check passes for the box but fails for h_test, the kernel is not flipped. If the output of the impulse check is shifted by one pixel, the padding is wrong. If the FFT check fails, the error is most likely in your derivation in Task 2a or in the limit at zero frequency.

Step 5: The Frequency Response of the Unsharp Mask

An unsharp mask sharpens an image by removing part of its unsharp, or low frequency, content. Let \(h\) be the \(5 \times 5\) average, which is box_kernel(2):

$$ h(m,n) = \left\{ \begin{array}{ll} 1/25 & \mbox{for } |m| \le 2 \mbox{ and } |n| \le 2 \\ 0 & \mbox{otherwise} \ . \end{array} \right. \tag{4} $$

Then \(x - h * x\) is the part of the image that the low-pass filter removes. The unsharp mask adds \(\lambda\) times that part back to the image. Its point spread function is

$$ g(m,n) = \delta(m,n) + \lambda \big( \delta(m,n) - h(m,n) \big) \ , \tag{5} $$

where \(\delta(m,n)\) is 1 at \((0,0)\) and 0 elsewhere, and \(\lambda > 0\) sets the amount of sharpening.

Step 7: The Frequency Response of the IIR Filter

An IIR filter is defined by a difference equation. Its output at each pixel depends on output values it has already computed. The filter in this module is

$$ y(m,n) = 0.01\, x(m,n) + 0.9 \big( y(m-1,n) + y(m,n-1) \big) - 0.81\, y(m-1,n-1) \ , \tag{6} $$

with \(x\) the input and \(y\) the output. Pixels outside the image are zero, for \(y\) as well as for \(x\), so the recursion starts at the top left corner from \(y = 0\). Let \(h(m,n)\) be the point spread function of the filter.

Step 9: The Separable Form

The factorization (7) says the filter is two 1-D recursions applied one after the other. The first recursion runs down each column:

$$ u(m,n) = x(m,n) + 0.9\, u(m-1,n) \ . \tag{8} $$

The second runs along each row:

$$ y(m,n) = 0.01\, u(m,n) + 0.9\, y(m,n-1) \ . \tag{9} $$

Each recursion is a loop over one index only. Recursion (8) loops over \(m\), and each step computes a whole row of \(u\) at once, for all columns and all channels. Recursion (9) loops over \(n\), and each step computes a whole column of \(y\) at once. So the separable form loops \(H + W\) times, where the direct form loops \(3HW\) times. These row and column loops are allowed. A loop over pixels is not. 

def iir_separable(x):
    """This function applies the IIR filter (6) as recursions (8) and (9).
