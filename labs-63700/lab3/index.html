Ground Rules

  • All filtering code is in PyTorch, in one file, lab3.py, run in the labs conda environment from Lab 2. NumPy and matplotlib are allowed for plotting.
  • lab3.py holds only functions. Run experiments from a separate script that imports it.
  • Use the exact signatures on this page, each with a short docstring.
  • Divide each image by 255 to scale it to \([0,1]\). Use float64.
  • A color image is a \((3, H, W)\) tensor. Filter each channel separately.
  • \(m\) counts rows from the top. \(n\) counts columns from the left.
  • All filters use free boundary conditions: pixels indexed outside the image are considered equal to zero.
  • Filtering will sometimes cause a pixel to exceed 1 or go below 0. Clip the pixel's value to \([0,1]\) before displaying or exporting the image, and not before.
  • No Python for loop over pixels, except in iir_direct (Step 8).
Run the checks in Steps 3, 5, 8, and 9 before you look at any filtered image. A filter with a mistake often still produces a plausible picture.

Step 1: Set Up lab3.py

import numpy as np
import torch
import torch.nn.functional as F
from PIL import Image


def load_image(path):
    """Read an 8-bit image file as a (C, H, W) float64 tensor in [0, 1]."""
    a = np.asarray(Image.open(path), dtype=np.float64) / 255.0
    if a.ndim == 2:
        a = a[:, :, None]
    return torch.from_numpy(a).permute(2, 0, 1).contiguous()


def save_image(x, path):
    """Clip a (C, H, W) tensor, C = 1 or 3, to [0, 1] and save it as an 8-bit PNG."""
    a = (x.clamp(0.0, 1.0) * 255.0).round().to(torch.uint8)
    a = a.permute(1, 2, 0).numpy()
    if a.shape[2] == 1:
        a = a[:, :, 0]
    Image.fromarray(a).save(path)


def box_kernel(p):
    """Return the (2p+1) by (2p+1) averaging kernel, every entry 1 / (2p+1)^2."""
    k = 2 * p + 1
    return torch.full((k, k), 1.0 / k**2, dtype=torch.float64)


def freq_grid(n):
    """Return n by n grids mu (down rows) and nu (across columns) in [-pi, pi)."""
    w = 2 * torch.pi * (torch.arange(n, dtype=torch.float64) - n // 2) / n
    return torch.meshgrid(w, w, indexing="ij")


def fft_magnitude(h, n):
    """Return |FFT| of h zero padded to n by n, centered to match freq_grid(n)."""
    return torch.fft.fftshift(torch.fft.fft2(h, s=(n, n))).abs()

Step 2: The Frequency Response

In this problem, you will analyze and implement a simple low pass filter given by the \(9 \times 9\) point spread function

$$ h(m,n) = \left\{ \begin{array}{ll} 1/81 & \mbox{for } |m| \le 4 \mbox{ and } |n| \le 4 \\ 0 & \mbox{otherwise} \ . \end{array} \right. \tag{1} $$

The DSFT of \(h(m,n)\) is

$$ H(e^{j\mu}, e^{j\nu}) = \sum_{m=-\infty}^{\infty} \sum_{n=-\infty}^{\infty} h(m,n) \, e^{-j(\mu m + \nu n)} \ , \tag{2} $$

where \(\mu\) goes with \(m\) and \(\nu\) with \(n\), in radians per sample.

Step 3: The FIR Filter and Its Checks

An FIR filter computes the 2-D convolution

$$ y(m,n) = \sum_{k} \sum_{l} h(k,l) \, x(m-k, n-l) \ , \tag{3} $$

with \(x = 0\) outside the image. Store \(h\) as an odd-size \(K \times L\) array with \(h(0,0)\) at h[K//2, L//2]. 

def fir_filter(x, h):
    """Return the convolution (3) of each channel of x (C, H, W) with h (K, L), K and L odd."""
  • Zero padding. The output has the same shape as the input.
  • One call to torch.nn.functional.conv2d, with the channels as the batch. No loop over pixels.
conv2d computes correlation, not convolution. Flip the kernel in both axes first. The symmetric kernels in this lab hide this mistake, and h_test below catches it.

Step 5: The Frequency Response of the Unsharp Mask

In this problem, you will analyze the effect of a sharpening filter known as an unsharp mask. The terminology comes from the fact that an unsharp mask filter removes the unsharp (low frequency) component of the image, and therefore produces an image with a sharper appearance.

Let \(h(m,n)\) be a low pass filter. For our purposes use box_kernel(2):

$$ h(m,n) = \left\{ \begin{array}{ll} 1/25 & \mbox{for } |m| \le 2 \mbox{ and } |n| \le 2 \\ 0 & \mbox{otherwise} \ . \end{array} \right. \tag{4} $$

The unsharp mask filter is then given by

$$ g(m,n) = \delta(m,n) + \lambda \big( \delta(m,n) - h(m,n) \big) \ , \tag{5} $$

where \(\delta(m,n)\) is 1 at \((0,0)\) and 0 elsewhere, and \(\lambda\) is a constant greater than zero.

$$ y(m,n) = 0.01\, x(m,n) + 0.9 \big( y(m-1,n) + y(m,n-1) \big) - 0.81\, y(m-1,n-1) \ , \tag{6} $$

Step 9: The Separable Form

By (7), the filter is a recursion down each column,

$$ u(m,n) = x(m,n) + 0.9\, u(m-1,n) \ , \tag{8} $$

followed by a recursion along each row,

$$ y(m,n) = 0.01\, u(m,n) + 0.9\, y(m,n-1) \ . \tag{9} $$

Each step of (8) computes a whole row of \(u\), for all columns and channels. Each step of (9) computes a whole column of \(y\). That is \(H + W\) loop steps, against \(3HW\) for the direct form. Row and column loops are allowed. A loop over pixels is not.
