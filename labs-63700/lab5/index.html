What This Lab Is About

Due: Friday, Feb. 12, 2027.

In this lab you find sets of connected pixels in an image. First you grow the set of pixels that are connected to one seed pixel. Then you segment the whole image into connected components, and you keep the large ones.

This is the one lab in the course that uses C. Region growing visits one pixel at a time, and each step depends on the steps before it, so it cannot be written as a few array operations. In Module 1 you write it in pure Python and time it. In Module 2 you write the same function in C and call it from Python, once for each component. Then you write a second C function that segments the whole image in one call. You check that all three versions agree, and you time them. You will see when compiled code pays off and when it does not.

You will not hand-write the implementation. This page states the definitions and the exact signature of every function you need. Then you run the experiments yourself, produce the required images and numbers, and explain what you see. You also read the C code and explain how it works. Step 1: Set Up lab5.py

Copy these helpers into lab5.py. load_image and save_image read and write 8-bit images as uint8 arrays. save_label_image writes a label image with a random color for each label, so that neighboring components are easy to tell apart. 

import ctypes
import os

import numpy as np
from PIL import Image


def load_image(path):
    """This function reads an 8-bit grayscale image file and returns it as an array.

    path     path to a PNG or TIFF file
    returns  (H, W) uint8 NumPy array with integer gray levels 0 to 255
    """
    return np.ascontiguousarray(np.asarray(Image.open(path).convert("L"), dtype=np.uint8))


def save_image(x, path):
    """This function writes an (H, W) uint8 array as an 8-bit grayscale PNG.

    x        (H, W) uint8 NumPy array
    path     output file name, ending in .png
    """
    Image.fromarray(np.asarray(x, dtype=np.uint8)).save(path)


def save_label_image(labels, path):
    """This function writes a label image as a color PNG with random colors.

    Label 0 is black.  Each label k > 0 gets a random color, and the colors
    come from a fixed seed, so the same labels always get the same colors.

    labels   (H, W) integer NumPy array of labels 0 to K
    path     output file name, ending in .png
    """
    k = int(labels.max())
    colors = np.random.default_rng(0).integers(40, 256, size=(k + 1, 3), dtype=np.uint8)
    colors[0] = 0
    Image.fromarray(colors[labels]).save(path)

Step 2: Neighborhoods and Connected Sets

Let \(S\) be the set of pixel locations, and let \(x_s\) be the gray level at the pixel \(s = (m, n)\). This lab uses the 4-point neighborhood, so the neighbors of \(s\) are

$$ \partial s = \big\{ (m-1, n), \ (m+1, n), \ (m, n-1), \ (m, n+1) \big\} \ . \tag{1} $$

The boundary is free. A neighbor that falls outside the image does not exist, so a pixel on the edge of the image has fewer than 4 neighbors.

Two neighbors are connected neighbors if their gray levels differ by at most a threshold \(T\). The connected neighbors of \(s\) are

$$ c(s) = \big\{ r \in \partial s \ : \ |x_s - x_r| \le T \big\} \ . \tag{2} $$

Two pixels \(s\) and \(r\) are connected if there is a path from \(s\) to \(r\) in which each pixel is a connected neighbor of the one before it. The set of all pixels connected to a seed pixel \(s_0\) is the connected set of \(s_0\). A connected component of the image is a set of pixels that is the connected set of each of its pixels.

The connected set is found by region growing. The algorithm keeps a list \(B\) of pixels that are known to be in the set but whose neighbors have not been checked yet. It also keeps a label image \(Y\), which marks the pixels that are known to be in the set.

Region growing from the seed \(s_0\).
  1. Set \(Y_{s_0} \leftarrow\) label and \(B \leftarrow \{s_0\}\).
  2. While \(B\) is not empty:
    1. Remove any pixel \(s\) from \(B\).
    2. For each \(r \in c(s)\) whose \(Y_r\) is not yet the label, set \(Y_r \leftarrow\) label and add \(r\) to \(B\).

The set grows outward from the seed, and \(B\) holds the pixels on the boundary of the region found so far. A pixel is labeled when it enters \(B\), so it enters \(B\) at most once. The order in which pixels leave \(B\) does not change the final set.

Step 3: Grow the Connected Set of a Seed

Direct your AI assistant to write the body of this function in pure Python. 

def connected_set(x, seed, T, label, seg):
    """This function labels every pixel connected to the seed, in pure Python.

    Two 4-point neighbors r and s are connected neighbors when
    |x[s] - x[r]| <= T.  The function keeps a list of pixels that are
    connected to the seed but not yet searched.  It sets seg = label at
    each connected pixel and treats a pixel whose seg already equals label
    as already found.

    x        (H, W) uint8 NumPy array
    seed     (row, col) of the seed pixel
    T        int, the threshold in gray levels
    label    int > 0, the label written into seg
    seg      (H, W) int32 NumPy array, changed in place
    returns  int, the number of pixels connected to the seed
    """

Four requirements.

  • The function follows the algorithm of Step 2, with an explicit Python list of unsearched pixels. It does not call itself recursively.
  • It reads and writes the NumPy arrays one element at a time. It does not convert the whole image to another type, because Step 4 calls it once for every component of the image.
  • It converts each gray level to a Python int before it subtracts. The difference of two uint8 values wraps around, so \(3 - 5\) gives 254.
  • It changes only the pixels of seg that are in the connected set.

Step 4: Segment the Whole Image

Every pixel belongs to exactly one connected component. To find all of them, scan the pixels in raster order, which is row by row from the top and left to right within a row. At each pixel that does not yet have a label, call connected_set with the next unused label. Then keep the components with more than 100 pixels, number them 1, 2, 3, and so on in the order the scan finds them, and set all other pixels to 0. 

def segment(x, T, min_size, connected_set_fn):
    """This function segments an image into connected components.

    It scans the pixels in raster order and calls connected_set_fn at each
    pixel that does not yet belong to a component.  Components with more
    than min_size pixels get labels 1 to K in the order the scan finds
    them, and all other pixels get label 0.

    x                 (H, W) uint8 NumPy array
    T                 int, the threshold in gray levels
    min_size          int, a component is kept if it has more than min_size pixels
    connected_set_fn  connected_set or connected_set_c
    returns           (labels, K, n_all): (H, W) int32 label array, the number
                      of kept components, and the number of all components
    """

The argument connected_set_fn lets Module 2 run the same segmentation with the C function. The relabeling at the end may use NumPy array operations.

Five requirements.

  • The region growing is written once, in a static helper function that both public functions call. The helper takes the list of unsearched pixels as an argument.
  • The list of unsearched pixels is an int array allocated with malloc, and it is released with free before the public function returns. segment_image allocates the list once and uses it for every component.
  • The list stores each pixel as its index m*width + n in the row-major array.
  • The list is large enough for every pixel of the image, so it cannot overflow. Explain in D5 why that size is enough.
  • The functions do not print, read files, or call exit.

Compile connect.c into a shared library in the folder that holds lab5.py. The same command works on a Mac, on Linux, and on WSL: 

cc -O2 -shared -fPIC -o libconnect.so connect.c

The option -O2 turns on the compiler's optimizations. -shared makes a library that other programs load, in place of a program with a main function. -fPIC makes code that runs at any address in memory, which a shared library needs. A Mac usually names a shared library with .dylib, but Python loads a .so file on a Mac just as well. Do not commit libconnect.so to GitHub, because it is a compiled file that each computer builds for itself.

Step 7: Call the C Function from Python

Copy these three functions into lab5.py. Python's ctypes module loads the library and calls the C functions. connected_set_c has the same signature as connected_set, so segment can use either one. segment_c returns the same values as segment. 

_LIB = None


def load_connect_library(path=None):
    """This function loads the compiled C library and declares its argument types.

    The library is loaded once and kept for later calls.  The default path
    is libconnect.so in the same folder as this file.

    path     path to the shared library, or None for the default
    returns  the ctypes library object
    """
    global _LIB
    if _LIB is None:
        if path is None:
            path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "libconnect.so")
        lib = ctypes.CDLL(path)
        lib.connected_set.restype = ctypes.c_int
        lib.connected_set.argtypes = [
            ctypes.c_void_p, ctypes.c_int, ctypes.c_int, ctypes.c_int,
            ctypes.c_int, ctypes.c_int, ctypes.c_int, ctypes.c_void_p]
        lib.segment_image.restype = ctypes.c_int
        lib.segment_image.argtypes = [
            ctypes.c_void_p, ctypes.c_int, ctypes.c_int, ctypes.c_int,
            ctypes.c_int, ctypes.c_void_p, ctypes.POINTER(ctypes.c_int)]
        _LIB = lib
    return _LIB


def connected_set_c(x, seed, T, label, seg):
    """This function labels every pixel connected to the seed, using the C library.

    It takes the same arguments and returns the same value as connected_set.
    The NumPy arrays are passed to C as pointers to their data, so x must be
    a C-contiguous uint8 array and seg a C-contiguous int32 array.
    """
    if x.dtype != np.uint8 or seg.dtype != np.int32 \
            or not x.flags.c_contiguous or not seg.flags.c_contiguous \
            or x.shape != seg.shape:
        raise TypeError("x must be C-contiguous uint8 and seg C-contiguous int32 of the same shape")
    lib = load_connect_library()
    H, W = x.shape
    count = lib.connected_set(x.ctypes.data, H, W, int(seed[0]), int(seed[1]),
                              int(T), int(label), seg.ctypes.data)
    if count < 0:
        raise MemoryError("connected_set in C could not allocate its list")
    return count


def segment_c(x, T, min_size):
    """This function segments an image into connected components with one call to C.

    It returns the same values as segment(x, T, min_size, connected_set_fn).
    x must be a C-contiguous uint8 array.

    x        (H, W) uint8 NumPy array
    T        int, the threshold in gray levels
    min_size int, a component is kept if it has more than min_size pixels
    returns  (labels, K, n_all): (H, W) int32 label array, the number of kept
             components, and the number of all components
    """
    if x.dtype != np.uint8 or not x.flags.c_contiguous:
        raise TypeError("x must be a C-contiguous uint8 array")
    lib = load_connect_library()
    H, W = x.shape
    labels = np.empty((H, W), dtype=np.int32)
    n_all = ctypes.c_int(0)
    K = lib.segment_image(x.ctypes.data, H, W, int(T), int(min_size),
                          labels.ctypes.data, ctypes.byref(n_all))
    if K < 0:
        raise MemoryError("segment_image in C could not allocate its arrays")
    return labels, K, n_all.value

x.ctypes.data is the memory address of the first element of x. C receives only that address. It does not receive the shape or the type, which is why the wrapper checks them before the call. A wrong type or a non-contiguous array would make C read the wrong bytes without any error message. segment_image returns the number of all components through the pointer n_all, and ctypes.byref(n_all) passes the address of a C integer that Python reads afterward.
