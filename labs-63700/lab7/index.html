What This Lab Is About

Due: Friday, Mar. 5, 2027.

In this lab you treat images as random vectors and study them through the eigen decomposition of their covariance. The eigenvectors of the covariance are the directions in which a set of images varies most, and they are used for image coding, image classification, and object recognition.

In Module 1 you generate Gaussian random vectors with a given covariance, estimate the covariance from the samples, and use its eigen decomposition to decorrelate and whiten them. In Module 2 you compute the eigenvectors of the covariance of a set of images of typed letters, called eigenimages. You compute them with the singular value decomposition (SVD) of the data matrix, without forming the covariance, and you rebuild an image from a few eigenimages. In Module 3 you use the eigenimages to reduce each letter image to 10 numbers and classify the letters with Gaussian maximum likelihood classifiers.

You will not hand-write the implementation. This page states the definitions and the exact signature of every function you need. Step 1: Set Up lab7.py

Copy these helpers into lab7.py. load_letters reads a folder of letter images into the columns of a data matrix, together with the letter of each column. to_image turns a column back into a 64 by 64 image for display. 

import os

import numpy as np
import torch
from PIL import Image

LETTERS = "abcdefghijklmnopqrstuvwxyz"


def load_letters(folder):
    """This function reads the letter images in folder into the columns of a data matrix.

    folder holds one subfolder for each font, and each subfolder holds the
    26 images a.png to z.png, each 64 by 64 pixels.  The fonts are read in
    alphabetical order, and the letters in the order a to z, so column
    26 * f + k holds letter k of font f.  Each image is flattened row by row.

    folder   path to the folder, for example "data/training"
    returns  X, a (4096, n) float64 tensor of gray levels 0 to 255;
             labels, an (n,) int64 tensor of letter numbers 0 (a) to 25 (z);
             fonts, the list of font names
    """
    fonts = sorted(d for d in os.listdir(folder)
                   if os.path.isdir(os.path.join(folder, d)))
    columns, labels = [], []
    for font in fonts:
        for k, letter in enumerate(LETTERS):
            img = np.asarray(Image.open(os.path.join(folder, font, letter + ".png")),
                             dtype=np.float64)
            columns.append(img.reshape(-1))
            labels.append(k)
    X = torch.from_numpy(np.stack(columns, axis=1))
    return X, torch.tensor(labels, dtype=torch.int64), fonts


def to_image(x):
    """This function reshapes a column of 4096 pixel values into a 64 by 64 image.

    x        (4096,) or (4096, 1) tensor
    returns  (64, 64) NumPy array, for display with matplotlib
    """
    return x.reshape(64, 64).detach().cpu().numpy()

Step 2: Gaussian Random Vectors

A Gaussian random vector \(X = [X_1, \dots, X_p]^t\) with mean \(\mu\) and covariance \(R\) has the density

$$ p(x) = \frac{1}{(2\pi)^{p/2} |R|^{1/2}} \exp\left\{ -\frac{1}{2} (x - \mu)^t R^{-1} (x - \mu) \right\} \ , \tag{1} $$

where \(\mu = E[X]\) is a \(p \times 1\) vector and \(R = E[(X - \mu)(X - \mu)^t]\) is a \(p \times p\) symmetric, positive definite matrix. In this step assume \(\mu = 0\).

Because \(R\) is symmetric, it has the eigen decomposition

$$ R = E \Lambda E^t \ , \tag{2} $$

where the columns of \(E = [e_1, \dots, e_p]\) are orthonormal eigenvectors, so \(E^t E = I\), and \(\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_p)\) holds the eigenvalues. The vector \(\tilde X = E^t X\) has covariance \(E^t R E = \Lambda\), so its components are uncorrelated, and, being Gaussian, independent. Its density is a product,

$$ p(x) = \prod_{k=1}^{p} \frac{1}{\sqrt{2\pi\lambda_k}} \exp\left\{ -\frac{\tilde x_k^2}{2\lambda_k} \right\} \ , \qquad \tilde x = E^t x \ . $$

So the contours of \(p(x)\) are ellipses whose axes point along the eigenvectors \(e_k\), with lengths proportional to \(\sqrt{\lambda_k}\). Scaling each component of \(\tilde X\) by \(1/\sqrt{\lambda_k}\) gives the whitened vector

$$ W = \Lambda^{-1/2} E^t X \ , \tag{3} $$

whose components are i.i.d. \(N(0, 1)\), so \(E[W W^t] = I\). Inverting equation (3) gives a way to generate \(X\) with covariance \(R\) from i.i.d. \(N(0, 1)\) samples:

$$ X = E \Lambda^{1/2} W \ . \tag{4} $$

In this step you generate vectors with the covariance

$$ R_X = \begin{bmatrix} 2 & -1.2 \\ -1.2 & 1 \end{bmatrix} \ . \tag{5} $$ 
def eig_sorted(R):
    """This function returns the eigenvalues and eigenvectors of a symmetric matrix, largest first.

    R        (p, p) float64 symmetric tensor
    returns  lam, a (p,) tensor of eigenvalues in decreasing order;
             E, a (p, p) tensor whose column k is the unit eigenvector of lam[k]
    """


def generate_gaussian(R, n, seed):
    """This function generates n Gaussian random vectors with zero mean and covariance R.

    It draws W with i.i.d. N(0, 1) entries, then forms X_tilde = Lambda^(1/2) W
    and X = E X_tilde, where R = E Lambda E^t.

    R        (p, p) float64 symmetric positive definite tensor
    n        number of vectors
    seed     int, seed of the torch.Generator that draws W
    returns  W, X_tilde, X, each a (p, n) float64 tensor with one vector per column
    """

Step 3: Covariance Estimation and Whitening

In practice the covariance is not known and must be estimated from data. Arrange \(n\) i.i.d. vectors as the columns of a \(p \times n\) data matrix \(X = [X_1, \dots, X_n]\). With an unknown mean, the unbiased estimates are

$$ \hat\mu = \frac{1}{n} \sum_{i=1}^{n} X_i \ , \qquad \hat R = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \hat\mu)(X_i - \hat\mu)^t = \frac{1}{n-1} Z Z^t \ , \tag{6} $$

where \(Z = [X_1 - \hat\mu, \dots, X_n - \hat\mu]\) holds the centered vectors. With the eigen decomposition \(\hat R = E \Lambda E^t\), the decorrelated and the whitened vectors are

$$ \tilde X_i = E^t (X_i - \hat\mu) \ , \qquad W_i = \Lambda^{-1/2} E^t (X_i - \hat\mu) \ . \tag{7} $$ 
def sample_mean_cov(X):
    """This function estimates the mean and covariance from the columns of a data matrix.

    X        (p, n) float64 tensor with one sample per column
    returns  mu, a (p, 1) tensor, the sample mean;
             R_hat, a (p, p) tensor, the unbiased covariance estimate with 1/(n-1)
    """


def decorrelate(X):
    """This function decorrelates the columns of X with the eigenvectors of their sample covariance.

    X        (p, n) float64 tensor with one sample per column
    returns  (p, n) float64 tensor X_tilde = E^t (X - mu), where mu and
             R_hat = E Lambda E^t come from sample_mean_cov(X)
    """


def whiten(X):
    """This function whitens the columns of X with their sample mean and covariance.

    X        (p, n) float64 tensor with one sample per column
    returns  (p, n) float64 tensor W = Lambda^(-1/2) E^t (X - mu), where mu
             and R_hat = E Lambda E^t come from sample_mean_cov(X)
    """

Step 4: Eigenvectors from the SVD of the Data Matrix

For images, the dimension \(p\) is the number of pixels. For the 64 by 64 letters \(p = 4096\), so \(\hat R\) is a \(4096 \times 4096\) matrix with nearly 17 million entries, and for a 400 by 400 image it would have about 25 billion. But there are only \(n = 312\) training images. The columns of \(\hat R\) are combinations of the same \(n\) centered vectors, so \(\hat R\) has rank at most \(n\) and at most \(n\) nonzero eigenvalues. These can be found without forming \(\hat R\).

The singular value decomposition of a \(p \times n\) matrix \(Z\) with \(p > n\), in its reduced form, is

$$ Z = U \Sigma V^t \ , \tag{8} $$

where \(U\) is \(p \times n\) and \(V\) is \(n \times n\), both with orthonormal columns (\(U^t U = V^t V = I\)), and \(\Sigma = \mathrm{diag}(\sigma_1, \dots, \sigma_n)\) holds the singular values \(\sigma_1 \ge \sigma_2 \ge \dots \ge 0\). The procedure is:

  1. Center the data and scale it: \(Z = (X - \hat\mu \mathbf{1}^t)/\sqrt{n-1}\), so that \(\hat R = Z Z^t\) by equation (6).
  2. Compute the reduced SVD \(Z = U \Sigma V^t\) with torch.linalg.svd(Z, full_matrices=False).
  3. The columns \(u_k\) of \(U\) are eigenvectors of \(\hat R\), and the eigenvalues are \(\lambda_k = \sigma_k^2\).

Task 4. Substitute equation (8) into \(\hat R = Z Z^t\) and show that \(\hat R u_k = \sigma_k^2 u_k\). Say why the remaining \(p - n\) eigenvalues of \(\hat R\) are 0.

Step 7: Projection Coefficients

Let \(U_m = [u_1, \dots, u_m]\) hold the first \(m\) eigenimages. The projection coefficients of an image \(x\) are

$$ y = U_m^t (x - \hat\mu) \ . \tag{9} $$

The vector \(y\) has \(m\) entries. It is not an image, but it describes the image by its coordinates along the directions of greatest variation, so it can serve as a feature vector.

Step 8: Resynthesis

An image can be approximated from its \(m\) projection coefficients by a combination of the eigenimages,

$$ \hat x = \hat\mu + \sum_{k=1}^{m} u_k y_k = \hat\mu + U_m y \ . \tag{10} $$

This approximation is principal component analysis (PCA). For a random image \(X\) with covariance eigenvalues \(\lambda_k\), its mean squared error is the sum of the eigenvalues that are left out,

$$ E\left[ \| \hat X - X \|^2 \right] = \sum_{k=m+1}^{p} \lambda_k \ , \tag{11} $$

so the largest eigenvalues give the best approximation with \(m\) terms. 

def resynthesize(Y, mu, U):

    U        (p, r) tensor of eigenimages, with r >= m
    returns  (p, n) tensor X_hat = U_m Y + mu, with m = Y.shape[0]
    """

Step 9: Gaussian Classification after PCA

A classifier assigns an input image \(x\) to one of the classes \(C_1, \dots, C_K\), here the \(K = 26\) letters. If the image in class \(C_k\) has the density \(p(x \mid C_k)\) and all classes are equally likely, the class with the largest posterior probability is the maximum likelihood (ML) class

$$ k^* = \arg\max_k \ p(x \mid C_k) \ . $$

If the images of class \(k\) are Gaussian, \(N(\mu_k, R_k)\), then taking \(-2\log\) of equation (1) and dropping the constant gives

$$ k^* = \arg\min_k \left\{ (x - \mu_k)^t R_k^{-1} (x - \mu_k) + \log |R_k| \right\} \ . \tag{12} $$

The first term is a weighted distance from \(x\) to the class mean. With \(p = 4096\) pixels and 12 training images per class, \(R_k\) cannot be estimated, and its estimate is not invertible. So first reduce each image to the vector \(y = A^t (x - \hat\mu)\) of equation (9), where \(A = U_{10}\) holds the first 10 eigenimages of the whole training set and \(\hat\mu\) is its mean image. Then apply equation (12) to \(y\), with the class means and covariances of the \(y\) vectors:

$$ \hat\mu_k = \frac{1}{N_k} \sum_{i=1}^{N_k} y_i^{(k)} \ , \qquad \hat R_k = \frac{1}{N_k - 1} \sum_{i=1}^{N_k} (y_i^{(k)} - \hat\mu_k)(y_i^{(k)} - \hat\mu_k)^t \ , \tag{13} $$

where \(y_i^{(k)}\) is the \(i\)-th training vector of class \(k\) and \(N_k = 12\) is the number of training vectors in class \(k\).

Step 10: Classify with the Full Class Covariance

The classifier uses a matrix \(B_k\) for each class in place of \(R_k\) in equation (12):

$$ k^* = \arg\min_k \left\{ (y - \hat\mu_k)^t B_k^{-1} (y - \hat\mu_k) + \log |B_k| \right\} \ . \tag{14} $$

In this step \(B_k = \hat R_k\). 

def scaling_matrices(covs, kind):

             "wc_diag"  B_k = diagonal of R_wc

    returns  (K, m, m) tensor of the B_k
    """

The full classifier makes errors, and one likely cause is that each \(\hat R_k\) is estimated from only 12 vectors. A more constrained matrix \(B_k\) has fewer entries to estimate. Try these four:

  1. "diag": \(B_k = \Lambda_k\), the diagonal of \(\hat R_k\). Each class has its own diagonal covariance.
  2. "wc": \(B_k = R_{wc}\), the average within-class covariance \(R_{wc} = \frac{1}{K} \sum_{k=1}^{K} \hat R_k\). All classes share one covariance.
  3. "wc_diag": \(B_k = \Lambda\), the diagonal of \(R_{wc}\). All classes share one diagonal covariance.
  4. "identity": \(B_k = I\). Each class has identity covariance around its own mean.

Each still measures the difference between \(y\) and the class mean \(\hat\mu_k\), but with a different weighting.
