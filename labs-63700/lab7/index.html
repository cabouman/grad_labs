What This Lab Is About

Due: Friday, Mar. 5, 2027.

It is often useful to view an image as a random process. An eigen decomposition of the covariance matrix reveals the principal directions of variation between images in a collection. This has applications in image coding, image classification, and object recognition. This lab explores image covariance, covariance estimation, and eigen decomposition of images. These ideas are then used to design a basic image classifier.

def load_letters(folder):
    """Read folder/font/letter.png into a data matrix; column 26 * f + k is letter k of font f (fonts sorted).

    returns  X, (4096, n) float64 gray levels 0 to 255; labels, (n,) int64 0 (a) to 25 (z); fonts, list of names
    """
    fonts = sorted(d for d in os.listdir(folder)
                   if os.path.isdir(os.path.join(folder, d)))
    columns, labels = [], []
    for font in fonts:
        for k, letter in enumerate(LETTERS):
            img = np.asarray(Image.open(os.path.join(folder, font, letter + ".png")),
                             dtype=np.float64)
            columns.append(img.reshape(-1))
            labels.append(k)
    X = torch.from_numpy(np.stack(columns, axis=1))
    return X, torch.tensor(labels, dtype=torch.int64), fonts

Step 2: Gaussian Random Vectors

A Gaussian random vector \(X = [X_1, \dots, X_p]^t\) with mean \(\mu\) and covariance \(R\) has the density

$$ p(x) = \frac{1}{(2\pi)^{p/2} |R|^{1/2}} \exp\left\{ -\frac{1}{2} (x - \mu)^t R^{-1} (x - \mu) \right\} \ , \tag{1} $$

where \(\mu = E[X]\), and the covariance \(R = E[(X - \mu)(X - \mu)^t]\) is positive definite and symmetric. In this step \(\mu = 0\). The eigen decomposition of \(R\) is

$$ R = E \Lambda E^t \ , \tag{2} $$

where the columns of \(E = [e_1, \dots, e_p]\) are the \(p\) eigenvectors of \(R\), and \(\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_p)\) contains the corresponding eigenvalues. Since \(R\) is symmetric, the eigenvectors are orthogonal and can be scaled to unit length, so \(E^t E = I\).

The eigen decomposition of \(R\) can be used to decorrelate and whiten \(X\). The components of \(\tilde X = E^t X\) are uncorrelated with diagonal covariance \(\Lambda\), and therefore independent in the Gaussian case. The contours of \(p(x)\) are ellipsoidal. Their principal directions are given by the eigenvectors in \(E\), and the lengths of the principal axes are proportional to \(\sqrt{\lambda_k}\). Normalizing the variance of each element of \(\tilde X\) produces a whitened random vector with i.i.d. \(N(0, 1)\) components,

$$ W = \Lambda^{-1/2} E^t X \ . \tag{3} $$

By inverting equation (3), the random vector \(X\) with covariance \(R\) can be generated by applying the transformation \(E \Lambda^{1/2}\) to the i.i.d. \(N(0, 1)\) random variables in \(W\):

$$ X = E \Lambda^{1/2} W \ . \tag{4} $$

In this step you use the covariance

$$ R_X = \begin{bmatrix} 2 & -1.2 \\ -1.2 & 1 \end{bmatrix} \ . \tag{5} $$

Step 3: Covariance Estimation and Whitening

We often do not know the true covariance, but we can obtain an estimate from a set of training data. Suppose we have \(n\) i.i.d. training vectors, arranged as columns in a \(p \times n\) data matrix \(X = [X_1, \dots, X_n]\). If the mean is unknown, the unbiased estimates are

$$ \hat\mu = \frac{1}{n} \sum_{i=1}^{n} X_i \ , \qquad \hat R = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \hat\mu)(X_i - \hat\mu)^t = \frac{1}{n-1} Z Z^t \ , \tag{6} $$

where \(Z = [X_1 - \hat\mu, \dots, X_n - \hat\mu]\) holds the mean-centered data vectors. With \(\hat R = E \Lambda E^t\), the decorrelated and whitened vectors are

$$ \tilde X_i = E^t (X_i - \hat\mu) \ , \qquad W_i = \Lambda^{-1/2} E^t (X_i - \hat\mu) \ . \tag{7} $$

def decorrelate(X):

Step 4: Eigenvectors from the SVD of the Data Matrix

The eigen decomposition of the sample covariance is often not practical for images, where the dimension \(p\) is the number of pixels and is much larger than the number of training images \(n\). The covariance of a 400 by 400 image would contain about 25 billion elements. However, the columns of \(\hat R\) are all linear combinations of the same \(n\) vectors, so \(\hat R\) has at most \(n\) nonzero eigenvalues. We can compute them, and their eigenvectors, without computing \(\hat R\), using the singular value decomposition (SVD). The SVD of a \(p \times n\) matrix \(Z\) with \(p > n\) is

$$ Z = U \Sigma V^t \ , \tag{8} $$

where both \(U \in \mathbb{R}^{p \times n}\) and \(V \in \mathbb{R}^{n \times n}\) have orthonormal columns, and \(\Sigma = \mathrm{diag}(\sigma_1, \dots, \sigma_n)\) holds the singular values in descending order. The procedure is:

  1. Form \(Z = (X - \hat\mu \mathbf{1}^t)/\sqrt{n-1}\), so that \(\hat R = Z Z^t\).
  2. Compute torch.linalg.svd(Z, full_matrices=False).
  3. The columns \(u_k\) of \(U\) are eigenvectors of \(\hat R\), with eigenvalues \(\lambda_k = \sigma_k^2\).

Task 4. Substitute equation (8) into \(\hat R = Z Z^t\) and show that \(\hat R u_k = \sigma_k^2 u_k\). Say why the other \(p - n\) eigenvalues are 0.

Step 8: Resynthesis

We can approximate the original image from a linear combination of the eigenimages,

$$ \hat x = \hat\mu + \sum_{k=1}^{m} u_k y_k = \hat\mu + U_m y \ . \tag{10} $$

The mean square error of this approximation is the sum of the remaining eigenvalues,

$$ E\left[ \| \hat X - X \|^2 \right] = \sum_{k=m+1}^{p} \lambda_k \ . \tag{11} $$

So the approximation is closest in the MSE sense if we use the largest eigenvalue components. This approximation is called principal component analysis (PCA). 

def resynthesize(Y, mu, U):

Step 9: Gaussian Classification after PCA

In a classification problem we are given an input image \(x\) that has to be assigned to one of several classes \(C_k\), here the \(K = 26\) letters. If all classes are equally likely, the class with the greatest posterior probability is the maximum likelihood (ML) class estimate \(k^* = \arg\max_k p(x \mid C_k)\). If the images in each class are Gaussian, \(N(\mu_k, R_k)\), then

$$ k^* = \arg\min_k \left\{ (x - \mu_k)^t R_k^{-1} (x - \mu_k) + \log |R_k| \right\} \ . \tag{12} $$

The first term is a weighted distance of the image to the class mean. Two issues arise with high-dimensional data. First, the estimate of \(R_k\) is often not invertible because of the limited training data. Second, each \(R_k\) is enormous. Both are addressed by transforming each image to the lower dimensional vector \(y = A^t (x - \hat\mu)\) of equation (9). Here \(A = U_{10}\) holds the first 10 eigenvectors of the whole training set, irrespective of class, and \(\hat\mu\) is its mean image. Then apply equation (12) to \(y\) with the class estimates

$$ \hat\mu_k = \frac{1}{N_k} \sum_{i=1}^{N_k} y_i^{(k)} \ , \qquad \hat R_k = \frac{1}{N_k - 1} \sum_{i=1}^{N_k} (y_i^{(k)} - \hat\mu_k)(y_i^{(k)} - \hat\mu_k)^t \ , \tag{13} $$

where \(y_i^{(k)}\) is the \(i\)-th training vector of class \(k\) and \(N_k = 12\).

Step 11: Constrained Covariances

A probable reason for the errors of D8 is the limited number of training images available for estimating each \(\hat R_k\). A more constrained matrix \(B_k\) might reduce the errors. Try these four:

  1. "diag": \(B_k = \Lambda_k\), the diagonal of \(\hat R_k\). Each class has a different diagonal covariance.
  2. "wc": \(B_k = R_{wc}\), the average within-class covariance \(R_{wc} = \frac{1}{K} \sum_{k=1}^{K} \hat R_k\). Each class has the same covariance.
  3. "wc_diag": \(B_k = \Lambda\), the diagonal of \(R_{wc}\). Each class has the same diagonal covariance.
  4. "identity": \(B_k = I\). Each class has identity covariance around a different mean.

Each case still computes the difference between the input and each class mean, but with a different scaling matrix \(B_k\).
