# grad_labs

Graduate laboratories in computational imaging, from ECE 60141,
"Foundations of Computational Imaging," at Purdue University.

The labs teach model-based image reconstruction: forward models and their
adjoints, MAP estimation with Gaussian and non-Gaussian edge-preserving
priors, optimization by majorization, Plug-and-Play, the EM algorithm, and
stochastic sampling. The code is written in Python with PyTorch.

The labs are served as web pages at https://cabouman.github.io/grad_labs/ .
